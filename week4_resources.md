## Practice Drill

After completing the listed problems, continue practice using Codeforces filters.

### Bit Manipulation

- Use the Codeforces problemset tag: `bitmasks`
- Start around rating **1100-1200**
- You may not find many good lower-rated problems for this topic, so do not worry if most useful problems start from around 1200

### Number Theory

- Use the Codeforces problemset tags:
  - `number theory`
  - `math`
  - `implementation`
- Practice problems with rating **1100+**
- Prefer the **1200** range if 1100 has very few suitable problems

## Suggested Approach

1. First cover the bit manipulation videos.
2. Solve the listed bit manipulation problems.
3. Watch the number theory playlist only up to video 15.
4. Solve the listed number theory problems.
5. Continue with the practice drill using topic and rating filters.
6. For every problem, spend enough time thinking before checking hints or editorials.
