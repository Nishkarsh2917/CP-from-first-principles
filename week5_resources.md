- Arrays

- Prefix Sums
- Time Complexity (O(N), O(N log N))

# Suggested Approach

1. Revise STL and Time Complexity.
2. Learn the basic Two Pointer pattern.
3. Solve easy Two Pointer problems.
4. Learn Fixed Size Sliding Window.
5. Learn Variable Size Sliding Window.
6. Solve the mandatory problems in order.
7. Attempt additional CSES and Codeforces problems.
8. Review editorials for every problem you couldn't solve.
9. Maintain notes of common patterns and observations.
